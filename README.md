# Tension Pool for Owlbear Rodeo

ส่วนขยาย Owlbear Rodeo สำหรับระบบ **Tension Pool** ในการสำรวจดันเจี้ยน

## กติกา
1. ทุก 10 นาทีในเกม เพิ่มเต๋า d6 1 ลูก
2. ทำกิจกรรมเสียงดัง เพิ่มอีก 1 ลูกทันที
3. ครบ 6 ลูก DM ทอยทั้งหมดพร้อมกัน ถ้ามีลูกใดออกหน้า 1 เกิดเหตุการณ์แทรกซ้อน
4. กด "เริ่มใหม่" เพื่อเคลียร์ Pool แล้วสะสมใหม่จาก 0

## ฟีเจอร์
- มีเสียงตอนเพิ่มเต๋า (add.mp3) และเสียงเต๋ากลิ้งตอนทอย Pool (roll.mp3)
- Counter แสดงจำนวนเต๋า และเต๋า 3 มิติหมุนทอยพร้อมกันทุกคนที่เห็น
- มีแต่ DM ที่เพิ่มเต๋า ทอย และเริ่มใหม่ได้
- DM เลือกได้ว่าจะเปิดเผย Pool ให้ผู้เล่นเห็นหรือไม่ (สวิตช์ "ให้ผู้เล่นเห็น Pool")
- DM เห็นโอกาสเกิดเหตุการณ์แทรกซ้อนของ Pool ปัจจุบัน
- ปุ่มทอยกดได้ตั้งแต่ 1 ลูก เผื่อ DM อยากทอยก่อนครบ 6 ลูก

## ติดตั้งผ่าน GitHub Pages
1. สร้าง repo แล้ว push โฟลเดอร์นี้ขึ้น branch `main`
2. Settings → Pages → Source เลือก **GitHub Actions** (workflow อยู่ใน `.github/workflows/pages.yml`)
3. รอ deploy เสร็จ จะได้ URL แบบ `https://<user>.github.io/<repo>/`
4. ใน Owlbear Rodeo: Profile → Add Extension → วาง `https://<user>.github.io/<repo>/manifest.json`

## หมายเหตุ
- ไม่ต้อง build ใช้ HTML/JS ล้วน โหลด Owlbear SDK จาก jsDelivr
- สถานะเก็บใน room metadata จึงคงอยู่ข้ามเซสชัน
- โหมดซ่อนจะซ่อนที่หน้าจอผู้เล่น แต่ข้อมูลยังอยู่ใน room metadata ผู้เล่นที่เขียนโค้ดอ่านเองได้ เหมาะกับโต๊ะเพื่อนฝูง ไม่ใช่ระบบกันโกงจริงจัง
- เปลี่ยนชื่อผู้เขียนใน `manifest.json` ก่อนเผยแพร่
